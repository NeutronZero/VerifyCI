# verifyci.evidence

## Overview
The `verifyci.evidence` package is responsible for building, signing, and projecting the canonical evidence bundle generated by VerifyCI. It implements deterministic JSON serialization strictly conforming to RFC 8785 (JCS), computes cryptographic payload digests, and projects verification results into standard SARIF v2.1.0 format for GitHub Code Scanning and CI ingestion.

## Interface
- `[bundle.py:utc_now]`: Generates an RFC 3339 formatted UTC timestamp string.
- `[bundle.py:toolchain_fingerprint]`: Computes a deterministic SHA-256 fingerprint representing the active verification toolchain.
- `[bundle.py:build_payload]`: Compiles the canonical inner payload containing run metadata, policy authority, git commits, check results, verdict, waivers, and acceptances.
- `[bundle.py:build_envelope]`: Envelopes the canonical payload with format version and cryptographic payload hash.
- `[bundle.py:build_bundle]`: Assembles and validates the complete `EvidenceBundle`.
- `[canonical.py:canonical_json_bytes]`: Serializes Python dictionaries and primitives into deterministic bytes conforming strictly to RFC 8785 (JCS).
- `[canonical.py:payload_hash]`: Computes the SHA-256 hex digest of canonicalized JSON bytes.
- `[sarif.py:bundle_to_sarif]`: Converts a canonical `EvidenceBundle` into standard SARIF v2.1.0 log format.

## Invariants
- `[canonical.py:canonical_json_bytes]`: Adheres strictly to RFC 8785: dictionary keys are sorted by UTF-16 code units, separators are comma and colon without trailing spaces, and floating-point representations follow canonical formatting.
- `[bundle.py:build_envelope]`: The `payload_hash` attribute must match the exact SHA-256 hex digest of the canonicalized payload bytes.
- `[sarif.py:bundle_to_sarif]`: Must emit valid SARIF v2.1.0 schema with driver name `"VerifyCI"` and rule definitions matching manifest check specs.

## Side Effects
- None: Pure in-memory transformation, hashing, and formatting operations.
