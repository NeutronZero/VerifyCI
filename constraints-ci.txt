# Pinned transitive constraints for the GitHub Action installer step.
#
# The composite action installs this repository from source
# (`pip install "${ACTION_PATH}"`). Source installs resolve `pyproject.toml`
# floors to whatever is newest at action-run time, so this file pins the exact
# versions resolved in `uv.lock` and a consumer run cannot float onto a yanked
# or breaking-major dependency.
#
# Regeneration (required whenever a runtime floor in pyproject.toml changes):
#   1. `uv lock`
#   2. `uv pip compile pyproject.toml -o constraints-ci.txt` (or extract the
#      1:1 versions from the `[[package]]` entries in `uv.lock`).
#
# Every entry below corresponds to a runtime dependency actually imported by
# `verifyci`; optional extras (temporal, embeddings, otel-semconv) are not
# pinned here because they are not installed by the action.
